📚 Documentación Técnica del Proyecto

1. Descripción del Sistema

Este sistema representa una Comunidad Energética Renovable que integra fuentes de energía solar fotovoltaica y eólica para el abastecimiento de una comunidad. El algoritmo implementado gestiona la distribución óptima de energía entre los productores y consumidores, minimizando la dependencia de la red eléctrica convencional.

2. Algoritmos Implementados

  • Algoritmo de Distribución de Carga: Asigna la energía generada prioritariamente al autoconsumo, luego al compartir comunitario y finalmente a excedentes.
  • Algoritmo de Balance Energético: Calcula en tiempo real el equilibrio entre generación y demanda.
  • Algoritmo de Optimización: Ajusta los parámetros de generación según las condiciones ambientales (radiación solar, velocidad del viento).
  • Estructuras de Datos: Arrays de objetos para productores, mapas para almacenamiento de métricas temporales.

3. Fórmulas Matemáticas Utilizadas

Producción Solar = Capacidad_Instalada × Factor_Radiación × Eficiencia_Paneles

Producción Eólica = Capacidad_Instalada × Factor_Viento

Balance_Energético = Σ(Generación) - Σ(Consumo)

Porcentaje_Autoconsumo = (Autoconsumo / Generación_Total) × 100

4. Características Técnicas

  • Lenguaje: JavaScript (ES6+)
  • Arquitectura: MVC (Modelo-Vista-Controlador)
  • Visualización: Chart.js para gráficos interactivos
  • Animaciones: CSS3 keyframes y transitions
  • Responsive: Grid y Flexbox para adaptación a dispositivos
  • Actualización: Tiempo real cada 5 segundos con variaciones aleatorias

5. Escenarios de Simulación

  • Alta Generación: Máxima radiación solar (mediodía) con consumo moderado
  • Alta Demanda: Hora pico vespertina con generación reducida
  • Equilibrio: Balance óptimo entre generación y consumo
  • Noche: Generación principalmente eólica con bajo consumo
